# Carpeta de imágenes del sitio

Sube aquí las imágenes que quieras usar en el contenido de SBN Ambiental
(fotos de proyectos, equipo, servicios, blog, etc.).

Ruta pública para referenciarlas en Markdown/HTML/front matter:

    /assets/images/uploads/nombre-del-archivo.jpg

Recomendaciones:
- Usa nombres en minúsculas y con guiones (ej: planta-tratamiento-sd.jpg).
- Formatos recomendados: .jpg o .webp para fotos, .png para gráficos con transparencia.
- Comprime las imágenes antes de subirlas (idealmente < 300-500 KB) para no afectar la velocidad del sitio.
